A modern, interactive learning platform designed for students following the **KTU (APJ Abdul Kalam Technological University) 2024 Scheme**. The application provides structured study material for **Foundations of Computing: From Hardware to Web Design (FOCFHWTWD)** through organized modules, interactive content, and a responsive user experience.

# 📦 Prerequisites

Before running the project, install:

- Node.js **v18 or later**
- npm (comes with Node.js)

Verify installation:

```bash
node -v
npm -v
```

---

# 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/ATS-001/FOCFHWTWD.git
```

### 2. Navigate into the project

```bash
cd FOCFHWTWD
```

### 3. Install dependencies

```bash
npm install
```

or

```bash
yarn install
```

or

```bash
pnpm install
```

---

# ▶️ Running the Development Server

```bash
npm run dev
```

or

```bash
yarn dev
```

or

```bash
pnpm dev
```

Open your browser and visit:

```
http://localhost:3000
```
